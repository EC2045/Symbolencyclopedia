# 翻訳ファイルの編集

翻訳は UTF-8 の `.lang` ファイルで管理します。

| ファイル | 言語 |
| --- | --- |
| `ja.lang` | 日本語（原文の参照用） |
| `ja-easy.lang` | やさしい日本語 |
| `ja-old.lang` | 古風日本語 |
| `en.lang` | 英語 |
| `zh.lang` | 中国語 |
| `eo.lang` | エスペラント語 |
| `shellvail-latn.lang` | シェルヴァイル語（ラテン文字・LTR／準備用） |
| `shellvail-rtl.lang` | シェルヴァイル語（シェル文字・RTL／準備用） |

## 書式

```text
# コメント
記号アーカイブ=Symbol Archive
```

左側は元の日本語、右側は訳文です。最初のエスケープされていない `=` が区切りになります。空行、行頭の空白に続く `#` / `;` のコメントは無視します。キーと値の空白は保存されます。

| 文字 | 記法 |
| --- | --- |
| 改行 | `\n` |
| タブ | `\t` |
| 復帰 | `\r` |
| `=` | `\=` |
| バックスラッシュ | `\\` |

キーは元の文章の前後の空白を除き、連続した空白・改行を半角スペース1個にまとめたものにしてください。訳文の改行は `\n` で記入できます。同じキーを重複させたり、区切りの `=` を省略すると、そのファイルの読み込みは失敗します。

`@title`、`@description`、`@locale` はページタイトル、説明、OGロケールです。

## 読み込み

`js/i18n.js` が起動時に8言語を読み込み、読み込み完了後にブラウザ設定または保存済みの言語を適用します。完了は `window.i18nReady` で待てます。言語切り替え時の再取得は不要です。読み込めない言語はコンソールにエラーを出し、従来と同じフォールバック（中国語・エスペラント語は英語、やさしい日本語・古風日本語は原文）を使用します。

日本語の本文はHTML・データベースの原文を表示します。`ja.lang` の本文エントリは翻訳用の原文一覧です。日本語のページ情報は `ja.lang` の `@` エントリから取得します。

翻訳の追加・修正は対象の `.lang` で行います。新しい言語自体を追加するときは `js/i18n.js` の `supportedLanguages`、言語判定、`index.html` の言語選択肢も追加してください。記号名など `js/ui.js` が個別に管理している表示処理は引き続きそちらで管理します。

GitHub Pages またはローカルHTTPサーバーで開いてください。`file://` から直接開くと `fetch` が制限されます。ビルドや追加ライブラリは不要です。

## シェルヴァイル語の翻訳準備

現時点では翻訳本文・ページ情報は未記入です。両ファイルには `ja.lang` の原文キーを用意しています。`日本語の原文=訳文` の右辺だけを埋めてください。空の訳文は未翻訳として扱います。

まず `shellvail-latn.lang` に通常の入力順でラテン文字の訳文を記入します。RTL版もこの訳文を共有します。`shellvail-rtl.lang` はシェル文字版だけ表記を変えたいキーに記入してください。RTL版の空欄は共有訳文、共有訳文も空欄なら日本語原文になります。通知・確認ダイアログ、入力欄の説明も同じフォールバックを使います。ブラウザの自動判定では選択せず、設定から手動で選べます。

HTMLの `lang` には私用タグ `x-shellvail-latn` / `x-shellvail`、`dir` には `ltr` / `rtl` を設定します。他言語に戻すと文字方向もLTRに戻ります。シェル文字にする翻訳本文の範囲だけを `.shellvail-script` で表示し、日本語の代替表示と言語選択肢は通常の字体・LTRを保ちます。ラテン文字版の訳文は `.shellvail-latin` で表示します。

シェル文字はラテン文字に字形を割り当てるフォントのため、`direction: rtl` と `unicode-bidi: isolate-override` を併用します。訳文を手動で反転する必要はありません。数字の並びはLTRに分離し、シェル文字の訳文は表示時にNFCへ正規化します。ブラウザのタブ、選択欄の項目、入力欄の説明やブラウザ標準ダイアログは通常のテキスト表示です。

フォントは指定された [Shellfun Regular](https://kgar.f5.si/fonts/shellfun-regular.otf) を `fonts/shellfun-regular.otf` に同梱しています。外部サイトのCORS設定に依存せず読み込めます。文法・表記の参照先は [シェルヴァイル語の概要](https://kgar.f5.si/shellvail#overview) です。
