# 翻訳ファイルの編集

翻訳は UTF-8 の `.lang` ファイルで管理します。

| ファイル | 言語 |
| --- | --- |
| `ja.lang` | 日本語（原文の参照用） |
| `ja-easy.lang` | やさしい日本語 |
| `ja-old.lang` | 古風日本語 |
| `en.lang` | 英語 |
| `zh.lang` | 中国語 |
| `eo.lang` | エスペラント語 |
| `shellvail.lang` | シェルヴァイル（LTR・RTL共用／準備用） |

## 書式

```text
# コメント
記号アーカイブ=Symbol Archive
```

左側は元の日本語、右側は訳文です。最初のエスケープされていない `=` が区切りになります。空行、行頭の空白に続く `#` / `;` のコメントは無視します。キーと値の空白は保存されます。

| 文字 | 記法 |
| --- | --- |
| 改行 | `\n` |
| タブ | `\t` |
| 復帰 | `\r` |
| `=` | `\=` |
| バックスラッシュ | `\\` |

キーは元の文章の前後の空白を除き、連続した空白・改行を半角スペース1個にまとめたものにしてください。訳文の改行は `\n` で記入できます。同じキーを重複させたり、区切りの `=` を省略すると、そのファイルの読み込みは失敗します。

`@title`、`@description`、`@locale` はページタイトル、説明、OGロケールです。

## 読み込み

`js/i18n.js` が起動時に7言語を読み込み、読み込み完了後にブラウザ設定または保存済みの言語を適用します。完了は `window.i18nReady` で待てます。言語切り替え時の再取得は不要です。読み込めない言語はコンソールにエラーを出し、従来と同じフォールバック（中国語・エスペラント語は英語、やさしい日本語・古風日本語は原文）を使用します。

日本語の本文はHTML・データベースの原文を表示します。`ja.lang` の本文エントリは翻訳用の原文一覧です。日本語のページ情報は `ja.lang` の `@` エントリから取得します。

翻訳の追加・修正は対象の `.lang` で行います。新しい言語自体を追加するときは `js/i18n.js` の `supportedLanguages`、言語判定、`index.html` の言語選択肢も追加してください。記号・事案・組織の名前も同じ `.lang` ファイルで編集できます。名前の訳文は従来の名前辞書より優先されます（英語の「より自然な英語名」を有効にした場合はその表記を優先）。未記入の場合は既存の表示に戻り、シェルヴァイルでは日本語の原名を表示します。

GitHub Pages またはローカルHTTPサーバーで開いてください。`file://` から直接開くと `fetch` が制限されます。ビルドや追加ライブラリは不要です。

## シェルヴァイルの翻訳準備

現時点では翻訳本文・ページ情報は未記入です。共通ファイルには `ja.lang` の原文キーを用意しています。`日本語の原文=訳文` の右辺だけを埋めてください。空の訳文は未翻訳として扱います。

翻訳は `shellvail.lang` だけを編集します。通常の入力順でラテン文字の訳文を記入してください。LTR・RTLは同じ辞書を参照し、個別の訳文や反転した文字列は保存しません。空欄は日本語原文になります。通知・確認ダイアログ、入力欄の説明も同じ辞書を使います。

設定の言語選択では「シェルヴァイル」を選び、別の「シェルヴァイルの表示」でラテン文字（LTR）／シェル文字（RTL）を切り替えます。表示形式は独立して保存されます。以前の `shellvail-latn` / `shellvail-rtl` の保存設定は共通言語 `shellvail` と対応する表示形式に自動移行します。ブラウザの自動判定では選択せず、設定から手動で選べます。

HTMLの `lang` には私用タグ `x-shellvail-latn` / `x-shellvail`、`dir` には `ltr` / `rtl` を設定します。他言語に戻すと文字方向もLTRに戻ります。シェル文字にする翻訳本文の範囲だけを `.shellvail-script` で表示し、日本語の代替表示と言語選択肢は通常の字体・LTRを保ちます。ラテン文字版の訳文は `.shellvail-latin` で表示します。

シェル文字はラテン文字に字形を割り当てるフォントのため、`direction: rtl` と `unicode-bidi: isolate-override` を併用します。訳文を手動で反転する必要はありません。数字の並びはLTRに分離し、シェル文字の訳文は表示時にNFCへ正規化します。ブラウザのタブ、選択欄の項目、入力欄の説明やブラウザ標準ダイアログは通常のテキスト表示です。

フォントは指定された [Shellfun Regular](https://kgar.f5.si/fonts/shellfun-regular.otf) を `fonts/shellfun-regular.otf` に同梱しています。外部サイトのCORS設定に依存せず読み込めます。文法・表記の参照先は [シェルヴァイルの概要](https://kgar.f5.si/shellvail#overview) です。


## 記号名の翻訳

`shellvail.lang` 末尾の「記号・事案・組織の名前」で、`日本語の名前=訳名` の右辺を記入してください。例（書式のみ）：

```text
句点和疑問符=ここに訳名を記入
```

一覧カード、詳細の見出しと名称、関連リンクに反映されます。LTR・RTLは同じ訳名を使い、シェル文字の字体・方向は表示設定から適用します。関連リンクのIDはLTRで表示します。空欄なら日本語の原名です。新規項目は日本語の名前をキーとして追加してください。同じキーがすでにある場合は、その行を編集してください。

## RTL時の画像と配置

シェルヴァイルのRTL表示では、記号・組織のカード画像と背景の記号画像をCSSで左右反転します。元画像と保存データは変更せず、LTR・他言語へ切り替えると元の向きに戻ります。画像の拡大・背景アニメーションと反転は併用されます。設定パネル、閉じるボタン、ラベルの罫線、余白も表示方向に合わせて配置されます。
